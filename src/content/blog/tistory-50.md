안녕하세요.

백엔드 개발을 공부하다 보면 관리자 페이지의 대시보드나 통계 리포트를 만들어야 할 때가 종종 있습니다. 이때 지역별 가입자 수나 월별 매출 같은 데이터를 뽑아내야 하는데, 단순히 그룹별 데이터뿐만 아니라 각 그룹의 소계(Subtotal)나 전체 총합계(Grand Total)가 필요한 경우가 많습니다.

이때 서버 코드에서 반복문을 돌며 일일이 합산을 구하고 계신가요? SQL의 WITH ROLLUP 문법을 알면 쿼리 한 번으로 이 모든 작업을 끝낼 수 있습니다.

오늘은 그룹핑의 끝판왕인 WITH ROLLUP에 대해 학생 입장에서 알기 쉽게 알아보겠습니다.

### 1. WITH ROLLUP이란?

간단히 말해 GROUP BY 결과에 대해 중간 합계와 총합계를 자동으로 계산해서 결과에 추가해 주는 문법입니다.

일반적인 GROUP BY는 명시된 컬럼끼리만 묶어서 보여주지만, 뒤에 WITH ROLLUP을 붙이면 그룹핑 기준 컬럼을 오른쪽에서부터 하나씩 해제하면서 상위 집계를 만들어냅니다.

### 2. 예시로 보는 작동 원리

이해를 돕기 위해 지역(region)과 성별(gender)을 기준으로 회원 수를 세는 상황을 가정해 보겠습니다.

쿼리: GROUP BY region, gender WITH ROLLUP

이 쿼리는 다음 3단계의 계층 구조로 데이터를 집계합니다.

1. 상세 데이터: 지역별, 성별 카운트 (A지역 남자는 몇 명?)
2. 중간 합계(소계): 지역별 전체 카운트 (성별 무시하고 A지역 전체는 몇 명?)
3. 총합계: 모든 지역, 모든 성별의 전체 카운트 (전체 회원은 몇 명?)

이 쿼리를 실행했을 때 DB 내부적으로 일어나는 일을 표로 보면 다음과 같습니다.

|  |  |  |  |
| --- | --- | --- | --- |
| **region** | **gender** | **count** | **설명** |
|  |  |  |  |
| --- | --- | --- | --- |
| 서울 | 남 | 10 | [1단계] 서울 사는 남자 수 |
| 서울 | 여 | 20 | [1단계] 서울 사는 여자 수 |
| 서울 | NULL | 30 | [2단계] 서울 지역 소계 (남+여) |
| 부산 | 남 | 5 | [1단계] 부산 사는 남자 수 |
| 부산 | 여 | 5 | [1단계] 부산 사는 여자 수 |
| 부산 | NULL | 10 | [2단계] 부산 지역 소계 (남+여) |
| NULL | NULL | 40 | [3단계] 전체 총합계 (서울+부산) |

여기서 가장 중요한 핵심 포인트는 NULL의 의미입니다.

WITH ROLLUP 결과에서 보이는 NULL은 데이터가 없다는 뜻이 아니라 전체(ALL)를 의미합니다.

- gender가 NULL이다: 성별을 구분하지 않고 합친 값
- region이 NULL이다: 지역을 구분하지 않고 합친 값

### 3. 실무 쿼리 분석 (HAVING 절 활용)

가끔 쿼리 예제에서 다음과 같은 조건을 볼 수 있습니다.

HAVING region IS NOT NULL

이 조건은 무엇을 의미할까요? 위 표에서 3단계에 해당하는 전체 총합계(region이 NULL인 행)를 제거하겠다는 뜻입니다.

즉, 전체 총합계는 필요 없고 지역별, 성별 상세 인원과 각 지역별 소계까지만 보고 싶을 때 이렇게 HAVING 절을 사용하여 필터링할 수 있습니다.

### 4. 백엔드 개발자가 이 기능을 써야 하는 이유

서버(Node.js, Java 등)가 아닌 DB에서 합계를 구해오면 다음과 같은 이점이 있습니다.

첫째, 애플리케이션 로직이 단순해집니다.

DB에서 소계를 계산해주지 않으면, 서버 코드에서 데이터를 받아온 후 for문을 돌며 변수(sum)를 만들어 직접 더하는 로직을 짜야 합니다. ROLLUP을 쓰면 쿼리 결과 자체에 합계가 포함되어 있으므로 코드가 훨씬 깔끔해집니다.

둘째, 네트워크 비용이 절약됩니다.

상세 데이터를 가져오는 쿼리 한 번, 합계를 구하는 쿼리 한 번, 이렇게 두 번 요청할 필요 없이 한 번의 요청으로 필요한 모든 통계 데이터를 가져올 수 있습니다.

### 주의할 점

만약 실제 데이터(예: 주소지가 입력되지 않은 회원) 자체가 NULL인 경우가 있다면, ROLLUP에 의해 생성된 합계 NULL과 헷갈릴 수 있습니다.

이때는 SQL의 GROUPING() 함수를 사용하면 해당 NULL이 실제 데이터인지, 아니면 ROLLUP에 의해 생성된 집계용 NULL인지 구분할 수 있습니다.

### 마치며

WITH ROLLUP은 복잡한 통계 쿼리를 아주 우아하게 해결해 주는 강력한 도구입니다.

결과 테이블에서 NULL이 보이면 당황하지 말고 아, 이건 해당 그룹의 합계(Total)구나!라고 이해하시면 됩니다.
